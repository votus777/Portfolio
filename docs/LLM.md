## AI 플레이버 큐레이터: 맞춤 향미 경험 추천 파이프라인

사용자와 대화하며 상황, 취향, 감정 상태를 이해해 어울리는 맛과 향의 조합을 제안하는 **AI 플레이버 큐레이터** 시스템의 핵심 흐름을 마크다운으로 정리

---

### 맛 프로필 생성 파이프라인

#### 1. 지능형 의도 분석 (Intent Analysis)
- **SEP 데이터 추출:**  
  사용자의 자연스러운 문장에서 상황(Situation), 감정(Emotion), 취향(Preference)을 자동 분리해 추출
- **예시:**  
   `"마감 후 홀가분하지만 조금은 차분해지고 싶어"` → 감정 벡터: *Relief + Calm*

- **시맨틱 특징 추출 (Semantic Feature Extraction)**
    LLM(Amazon Bedrock)은 '화려한 파티'라는 문장을 단순한 텍스트가 아닌, 여러 가지 **잠재적 속성(Latent Features)**의 집합으로 분해 

    - 분위기(Mood): 고조된(High energy), 사교적인(Social), 고급스러운(Premium).

    - 물리적 연상: 차가운(Cool), 탄산감(Sparkling), 밝은 색상(Bright).

    - 맛의 방향성: 무거운 쓴맛보다는 가벼운 산미(Acidic)나 화사한 향(Floral).

- **Context Buffer:**  
  이전 대화 내역(예: *"지난번에 마셨던 시트러스는 좋았어"*)을 활용해 사용자의 지속적인 향미 취향을 기억, 반영

#### 2. RAG 기반 화학 성분 검색 (Knowledge Retrieval)
- **지식 검색:**  
  파악된 맥락에 맞는 화학 성분을 12만 종 이상의 DB에서 검색
    - 예시: *'차분함'* → 테르펜(Terpene), *'홀가분함'* → 가벼운 에스테르(Ester)
- **성분 매핑:**  
  감정 벡터와 유사도가 높은 상위 성분 후보군을 추려 사용자 경험에 적합한 구성요소를 추천

#### 3. 에이전트 기반 레시피 합성 (Reasoning & Action)
- **실제 레시피 생성:**  
  LLM의 단순 추천을 넘어, 추출 성분 기반으로 **강화학습(AWS Lambda)**를 활용해 제조 가능한 최적 배합 레시피를 합성
- **상호작용적 조율:**  
  성분 조합이 불안정하거나 재료가 부족하면,  
  `"이 향을 구현하기 위해 탄산감을 조금 높여도 괜찮을까요?"`  
  와 같이 사용자와 실시간 상호작용해 레시피를 조정

#### 4. 안전성 Guardrails 및 최종 출력
- **식품위생 및 내용 필터링:**  
  Amazon Bedrock의 Guardrails로 금지 성분 조합, 부적절/신뢰할 수 없는 레시피, 부적합 대화 내용을 자동 감지·차단해 안전하고 신뢰성 높은 결과만 제공

맛 규격을 정하는 가장 정석적인 방법은 **플레이버 휠(Flavor Wheel)**을 데이터의 **기반 체계(Taxonomy)**로 채택하는 것

1. 플레이버 휠을 활용한 표준 어휘(Lexicon) 정의
업계 공인 표준(ISO 5492 등)에 기반한 플레이버 휠의 용어들을 규격으로 사용

계층적 분류: 플레이버 휠의 대분류(예: Fruity), 중분류(예: Citrus), 소분류(예: Lemon)를 트리 구조로 DB화

속성 확정: 당신의 서비스에 핵심적인 10~20개의 **감각 기술어(Sensory Descriptors)**를 선정

예: Flavor_Woody, Flavor_Floral, Flavor_Acidic, Body_Heavy 등.


2. 수치 규격화 (Intensity Normalization)
각 어휘를 AI가 계산할 수 있도록 0.0에서 1.0 사이의 벡터 값으로 변환하는 과정.

강도 수치화: "약간 쌉쌀한"은 Bitter: 0.3, "강렬하게 쓴"은 Bitter: 0.9로 규격화.

프로필 생성: 하나의 제품이나 질의는 여러 속성의 조합인 '맛 프로필(JSON)' 규격을 갖게됨

{"Floral": 0.8, "Citrus": 0.5, "Sweet": 0.2}

임베딩 거리: Text2Mol 방식처럼, 이 수치 데이터는 VectorDB(AOSS) 내에서 특정 좌표를 형성하며 자연어 질의와 비교되는 기준점


단계	항목	역할	기준 (Criteria)
언어 규격	Sensory Lexicon	단어의 표준화	플레이버 휠 (ISO/ASTM 표준)
데이터 규격	Intensity (0~1)	강도의 수치화	LLM의 부사/형용사 분석
물리 규격	Chemical Link	성분과의 결합	보유 중인 맛-화학 DB (SMILES)
